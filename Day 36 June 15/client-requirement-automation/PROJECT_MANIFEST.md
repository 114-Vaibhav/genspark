## 📄 FILE DESCRIPTIONS

### Core Application Files

#### 1. **automate.py** (Main Automation Script)
- **Purpose**: Orchestrates the entire workflow
- **Size**: ~700 lines of well-commented Python
- **Key Features**:
  - Reads client requirement email from text file
  - Reads LLM-generated markdown output from Gemini/Claude
  - Converts markdown to professional HTML with native Python
  - Creates formatted HTML email body with navy color scheme
  - Sends email via Gmail using SMTP with TLS encryption
  - Comprehensive logging to console and file
  - Extensive error handling with helpful messages
  
- **No External Dependencies**: Uses only Python standard library
  - `smtplib` - Gmail SMTP client
  - `email` - Email message formatting
  - `logging` - Application logging
  - `pathlib` - File path operations
  - `datetime` - Timestamp generation
  
- **Configuration Required**:
  ```python
  Config.SENDER_EMAIL = "your-email@gmail.com"
  Config.SENDER_PASSWORD = "your-app-password"  # 16-char Google App Password
  Config.RECIPIENT_EMAIL = "target@company.com"
  ```
  
- **Usage**: `python3 automate.py`

### Input Files

#### 4. **inputs/requirements.txt**

#### 5. **inputs/Gemini_output.txt**
- **Purpose**: Structured requirements generated by Claude/Gemini
- **Format**: Markdown with clear sections
- **How to Generate**:
  1. Copy system prompt from `config/SYSTEM_PROMPT.md`
  2. Paste into Claude.ai or Gemini.google.com
  3. Paste client email text after prompt
  4. Save Claude/Gemini response to this file
  
- **Expected Sections**:
  - Functional Requirements (Must-Have, Should-Have, Could-Have)
  - Non-Functional Requirements (Performance, Security, Scalability)
  - Technical Constraints & Assumptions
  - Identified Risks & Challenges
  - Questions for Client Clarification
  
- **Format**: Markdown with headers, lists, bold, code blocks
- **Role in Workflow**: Main content converted to HTML email

## 🔄 Workflow Process

```
┌─────────────────────────────────────────────────────────────────┐
│                      AUTOMATION WORKFLOW                         │
└─────────────────────────────────────────────────────────────────┘

1️⃣  PREPARE INPUTS
    └─→ Save client email → inputs/requirements.txt

2️⃣  GENERATE STRUCTURED REQUIREMENTS
    ├─→ Copy config/SYSTEM_PROMPT.md
    ├─→ Paste into Claude or Gemini
    ├─→ Paste client email
    └─→ Save output → inputs/Gemini_output.txt

3️⃣  CONFIGURE EMAIL
    └─→ Update automate.py (email, password, recipient)

4️⃣  RUN AUTOMATION
    ├─→ Execute: python3 automate.py
    └─→ Script:
        ├─ Reads inputs/requirements.txt
        ├─ Reads inputs/Gemini_output.txt
        ├─ Converts markdown → HTML
        ├─ Creates professional email
        ├─ Saves outputs/email_output.html
        └─ Sends via Gmail

5️⃣  VERIFY & DELIVER
    ├─→ Check HTML in browser (outputs/email_output.html)
    ├─→ Verify email received
    ├─→ Review logs (logs/automation_*.log)
    └─→ Forwad email or share HTML
```
